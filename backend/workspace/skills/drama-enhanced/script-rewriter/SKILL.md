# 剧作：用行动改变局面

来源：zenstory-ai/drama-skills 0.11.2 的 short-drama-write（MIT）；本文件是映作适配，不是上游原文。

先 read_episode_script；有当前剧本时以当前剧本为准，原文用于查事实。用 save_script 保存请求范围的完整结果。
沿用本应用格式：`## S编号 | 内景/外景 · 地点 | 时间段`，动作自然段，`角色名：（状态）台词`；需要时标出 [VO]、[OS]、[SFX]、[连续性]。

- 先明确谁想要什么、阻力、当前代价和本集退出状态。在上下文排“因为—行动—结果—下一股压力”，不新增用户没给出的身份、金额、权限和救场机关。
- 开场第一拍让人看懂眼前的冲突。每场改变信息、权力、关系、情绪或物理状态；删除同义羞辱、重复解释与空喊狠话。
- 台词让人物争取、试探、拒绝或逼迫；能用动作兑现的内容先演出来。配角保留合理动机，对手的转向需要有事实或行动支撑。
- 保留用户原文和点名范围。局部改写不重做整集，不为模板硬加反转。让动作和停顿承载反应，结尾兑现已铺垫的变化。
- 按完整对白、语气、不可重叠动作、停顿估算时长，标明估算前提；实际录音可用时以录音为准。没有目标集长时不按固定字数或场景秒数凑稿。
- 交接可见的退出状态：谁知道了什么、谁持有物件、服装/伤势/空间有何变化。连续性标签只记录已发生事实。

按需通过本地文件读取工具查原文知识（路径相对工作目录）：
- `drama-skills/short-drama-write/references/script-craft.md`：压稿、钩子、因果、结尾。
- `drama-skills/short-drama-write/references/dialogue-craft.md`：潜台词、人物腔调。
- `drama-skills/short-drama-write/references/scene-sound-dramaturgy.md`：声音、留白。

完成后报告实际保存结果和真实未决项。不要把自检写成质量保证。
